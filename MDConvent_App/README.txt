## SETUP KARNE KA TARIKA (HINDI)

### STEP 1 - Node.js Install Karo (Sirf ek baar)
1. Browser mein jao: https://nodejs.org
2. "LTS" wala download karo (bada green button)
3. Download hone ke baad open karo
4. Bas "Next Next Next Finish" karo - kuch change mat karo

### STEP 2 - App Chalao
1. Is folder mein `INSTALL_AND_RUN.bat` file pe double click karo
2. Pehli baar thoda time lagega (2-3 minute) - internet chahiye
3. App apne aap khul jayegi!

### STEP 3 - Agle baar se
- Sirf `START_APP.bat` pe double click karo
- App seedha khul jayegi

## DATA KAHAAN SAVE HOTA HAI?

## BACKUP LENA
- App ke andar > Reports > "Backup All Data"
- Ek .json file Desktop pe save hogi
- Ye file safe rakh - isme sara data hoga
