# MD Convent SMS — Demo Data Test Kit

Standalone testing suite for generating synthetic school management databases for `MDConvent_App`.

## Usage
```bash
node DEMO_TEST_KIT/generate_demo_data.js [count]
```
Example:
```bash
node DEMO_TEST_KIT/generate_demo_data.js 150
```
Outputs to `DEMO_TEST_KIT/demo_data/demo_school_data.json`.
