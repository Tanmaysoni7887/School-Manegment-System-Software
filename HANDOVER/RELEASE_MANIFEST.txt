HOW TO VERIFY FILE INTEGRITY ON WINDOWS
--------------------------------------------------------------------------------
To verify the installer before installing, open Windows PowerShell in this folder
and run:

  Get-FileHash -Path "Installer\MD_Convent_SMS_Setup_v2.0.exe" -Algorithm SHA256

Compare the output hash to the official release hash:
  0B562AE0DC8122754F6A24770443B6CA6029DD8D10E346E663CD623019D5D92E
